# Redbrick AI

Redbrick provides members with access to a self-hosted AI platform powered by Redbrick's own GPU infrastructure.

The service uses **Open WebUI** and provides access to several AI models for general use, programming, learning, and experimentation.

## Access

Open:

[https://ai.rb.dcu.ie/](https://ai.rb.dcu.ie/)

Sign in using your normal:

- **Redbrick username**
- **Redbrick password**

Authentication is handled through Redbrick LDAP, so you do not need to create a separate account.

## Available models

Redbrick hosts several AI models, including general-purpose, coding, and reasoning models.

The currently available models can be selected from the model picker in Open WebUI.

The model list may change over time as models are added, removed, or updated.


## Important notes

AI-generated responses can be incorrect, outdated, or misleading. Verify important information and test generated code before relying on it.

Do not submit sensitive information such as:

- Passwords
- Private SSH keys
- API keys
- Authentication tokens
- Confidential information

The service uses shared Redbrick GPU resources, so response speed and model availability may vary depending on current usage.

## Need help?

If you cannot log in, a model is unavailable, or the service is not working correctly, contact the Redbrick admins through Discord.

See the **[Links](/links)** page for ways to get in touch.
