# Matrix

Redbrick runs its own [Matrix](https://matrix.org/) instance, providing members with an open and decentralised alternative to Discord for chatting with the Redbrick community.

The Redbrick Matrix instance is bridged with the Redbrick Discord server, so messages can be sent between Matrix and Discord. People joining from Matrix may appear as bridged users on Discord.

## Getting started

You can sign in using your **Redbrick username and password**.

Redbrick hosts several Matrix web clients, so you can choose whichever interface you prefer:

- **[Element](https://element.redbrick.dcu.ie/)** — a full-featured Matrix client.
- **[Cinny](https://cinny.redbrick.dcu.ie/)** — a lightweight client with a Discord-like interface.
- **[Hydrogen](https://hydrogen.redbrick.dcu.ie/)** — a minimal and lightweight Matrix client.


## Join the Redbrick room

The main Redbrick Matrix room is:

`#redbrick:redbrick.dcu.ie`

You can open it directly using the Redbrick Matrix instance:

**[Join the Redbrick room](https://matrix.redbrick.dcu.ie/#/room/#redbrick:redbrick.dcu.ie)**

## Using another Matrix client

If you use your own Matrix client, configure the Redbrick homeserver as:

```text
https://matrix.redbrick.dcu.ie
```
 
Then sign in using your Redbrick account.

## Discord bridge

The main Redbrick Matrix room is bridged with Discord. This means Matrix users can communicate with people in the Redbrick Discord server without needing to use Discord directly.

Messages sent from Matrix will appear in Discord through the bridge, and messages from Discord will appear in Matrix.

## Need help?

If you have trouble logging in, connecting to the homeserver, or using the Discord bridge, contact the Redbrick admins through Discord or the usual support channels.

See the **[Links](/links)** page for ways to get in touch.
