# Minecraft Hosting

Redbrick runs its own Minecraft server for members and can also host separate Minecraft servers on request.

## Redbrick Minecraft server

Redbrick's main vanilla Minecraft server is available at:

```text
vanilla-mc.rb.dcu.ie
```

Add the address in Minecraft as a multiplayer server to connect.

### Link your Minecraft account

Before joining, link your Minecraft username to your Redbrick account through Blockbot in the Redbrick Discord server.

Use:

```text
/account link minecraft
```

Enter your Minecraft username in the `minecraft_name` field and submit the command.

For example:

```text
/account link minecraft YourMinecraftName
```

Once your account is linked, you can connect to:

```text
vanilla-mc.rb.dcu.ie
```

## Live map

The Minecraft server also provides a browser-based map.

Open:

[https://vanilla-mc.rb.dcu.ie/](https://vanilla-mc.rb.dcu.ie/)

The same hostname is therefore used both to connect from Minecraft and to view the server map in your browser.

## Request a Minecraft server

Redbrick can also host Minecraft servers for members, groups, societies, or events.

Server hosting is currently handled by the sysadmins on request rather than through an automatic provisioning system.

To request a server, open a ticket with the Redbrick sysadmins on Discord.

When opening the ticket, include what you want to run and any requirements you already know about, such as:

- Minecraft version
- Vanilla, modded, or plugin-based server
- Expected number of players
- Mods or plugins you want to use
- Whether the server is for a society, event, project, or personal use
- Any unusual CPU, memory, storage, or networking requirements

The sysadmins will discuss the requirements with you and determine what Redbrick infrastructure can provide.

Hosting requests are subject to available resources and approval by the sysadmins.

## Server usage

Hosted services should not be malicious or unnecessarily resource-intensive.

If a hosted server is no longer being used, the admins may contact you about decommissioning it so that the resources can be reused.

If your requirements change after the server has been created, contact the sysadmins rather than attempting to work around the allocated resources.

## Need help?

For problems with the Redbrick Minecraft server, account linking, the live map, or a hosted Minecraft server, contact the Redbrick sysadmins through Discord.
