# What Redbrick Provides

Redbrick provides members with a range of services hosted and maintained by the society.

Some services are available immediately with your Redbrick account, while others can be requested from the sysadmins depending on what you want to run.

## Available services

- **[AI](/services/ai)** — use Redbrick's self-hosted AI platform and models running on Redbrick GPU infrastructure.

- **[Linux Shell Access](/services/ssh)** — connect to Redbrick's Linux login servers over SSH for development, file management, hosting, and general command-line use.

- **[Minecraft Hosting](/services/minecraft)** — join Redbrick's Minecraft server or request a separate Minecraft server for yourself, a group, society, or event.

- **[Matrix](/services/matrix)** — chat with the Redbrick community through Redbrick's Matrix instance and its bridge to Discord.

- **[Personal Webspace](/services/web-hosting)** — host a personal website, portfolio, documentation, or project using the webspace included with your Redbrick account.

## Quick access

These services can be accessed directly without requesting separate hosting or additional setup.

### Webmail

Access your Redbrick email from your browser.

[Open Webmail](https://webmail.redbrick.dcu.ie/)

Sign in using your Redbrick username and password.

### HedgeDoc

Create and collaborate on Markdown notes and documents in real time.

[Open HedgeDoc](https://md.redbrick.dcu.ie/)

Sign in using your Redbrick account.

### Redbrick Wiki

Browse Redbrick guides, history, documentation, and community-maintained articles.

Members can sign in to edit and contribute.

[Open the Wiki](https://wiki.redbrick.dcu.ie/)

### Redbrick Search

Search the web using Redbrick's SearXNG instance.

[Open Redbrick Search](https://search.redbrick.dcu.ie/)

### PrivateBin

Create and share encrypted text pastes using Redbrick's PrivateBin instance.

[Open PrivateBin](https://paste.redbrick.dcu.ie/)

## Need something hosted?

Redbrick can also provide additional infrastructure on request, including:

- MySQL and PostgreSQL databases
- Virtual machines
- WordPress hosting
- Discord bot hosting
- Password manager access
- Other application or server hosting

See **[Request a Service](/services/request-services)** for more information about what is available and how to contact the sysadmins.
