# Request a Service

Redbrick can provide additional hosting and infrastructure to members and DCU clubs and societies on request.

These services are provisioned by the sysadmins rather than being automatically enabled on every Redbrick account.

## How to request a service

Open a ticket with the Redbrick sysadmins on Discord and explain what you want to run.

Include any useful information such as:

- What you want to host
- Whether it is for yourself, a project, club, society, or event
- Expected usage
- Storage, memory, CPU, or networking requirements
- Any software or database requirements

The sysadmins will discuss the requirements with you and determine what Redbrick can provide.

## Databases

MySQL and PostgreSQL databases can be provided for projects that need persistent database storage.

If you need a database, include the database type and what you intend to use it for in your request.

## Password Manager

Access to Redbrick's password manager can be created on request.

This is useful for members, projects, or societies that need to securely manage shared credentials.

## Virtual Machines

Redbrick can provide virtual machines for workloads that require their own operating system or environment.

VM specifications are decided with the sysadmins based on the requirements of the project and available resources.

## WordPress Hosting

Redbrick can host WordPress websites for DCU clubs, societies, and other suitable projects.

If you need WordPress hosting, open a ticket and describe the website, expected usage, and any domain requirements.

## Discord Bot Hosting

Redbrick can host Discord bots in the same way as other hosted applications.

Include the bot's runtime, resource requirements, and any database or networking requirements when opening your request.

## Other hosting

If what you want to run does not fit one of the categories above, you can still ask.

Provided the service is suitable for Redbrick infrastructure and resources are available, the sysadmins can discuss possible hosting options with you.

## Need help?

Open a ticket or contact the Redbrick sysadmins through Discord.

See the **[Links](/links)** page for ways to get in touch.
